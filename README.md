# AssetFlow - Enterprise Asset & Resource Management System

## 📌 Overview

AssetFlow is a web-based Enterprise Asset & Resource Management System developed to help organizations efficiently manage assets, employees, departments, resource bookings, maintenance requests, and asset audits.

The system provides a centralized platform for tracking organizational assets throughout their lifecycle, improving transparency, reducing manual work, and increasing operational efficiency.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 👤 Employee Management
- 🏢 Department Management
- 📦 Asset Registration & Tracking
- 🔄 Asset Allocation & Return
- 📅 Resource Booking System
- 🛠️ Maintenance Request Management
- 📋 Asset Audit
- 📊 Dashboard & Reports
- 🔔 Notifications
- 🔍 Search & Filter Assets
- 📱 Responsive User Interface

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/AssetFlow.git
```

### 2. Navigate to the Project Folder

```bash
cd AssetFlow
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

The application will start on:

```
http://127.0.0.1:5000/
```
